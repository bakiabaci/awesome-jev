# Contributing to Awesome Jev

Thank you for contributing to the community index of Jev, Laya, and System One typed decision models.

### Guidelines for Inclusion

1. **Concrete Typed Decision Loop**: The repository must showcase a concrete typed decision interface (`Choice`, `Noul`, `Score`) or wire compatibility with `/v1/systemone`.
2. **Quality & Maintenance**: Projects should have clear documentation, runnable examples or install steps, and an open license.
3. **Format**: Follow the existing list format:
   ```markdown
   * [project-name](https://github.com/owner/project-name) (★stars) - Short, objective description of what it does and which problem it solves.
   ```
4. **No Unaffiliated Hype**: Avoid marketing superlatives; state clearly what the project does, its latency/runtime characteristics, and any notable constraints.

### Submission Process

1. Fork the repository.
2. Add your project under the most relevant section in `README.md`.
3. Keep alphabetical or star ordering within the section.
4. Submit a Pull Request with a brief summary of the project.
